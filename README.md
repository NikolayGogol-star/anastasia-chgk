# Особая игра для Анастасии

Готовый статический костяк для GitHub Pages. Сборка и установка библиотек не нужны.

## Запуск

Откройте `index.html` в браузере или запустите в этой папке `python3 -m http.server 8080` и перейдите на `http://localhost:8080`.

## Вопросы и видео

В `questions.js` сейчас 13 демонстрационных вопросов. Замените текст и ответы своими. Поместите MP4 в `assets/`, затем укажите `video: 'assets/01.mp4'` у нужного вопроса. Рекомендуется MP4 с видео H.264 и аудио AAC. Все пути относительные, поэтому сайт подходит для страницы репозитория GitHub Pages.

Пример:

```js
{id:1, author:'Мария', title:'Вопрос от Марии', video:'assets/01.mp4',
 text:'Текст вопроса для резервного просмотра',
 answer:'Правильный ответ', explanation:'Почему это правильный ответ'}
```

После окончания видео автоматически начинается минута. Для текстового вопроса она запускается кнопкой. Закрытие окна вопроса и уход на другую вкладку ставят таймер на паузу. При возвращении продолжите его кнопкой. Ответ можно написать или произнести вслух. Анастасия сама засчитывает ответ; игра идёт до 6 очков, затем оставшиеся вопросы доступны вне зачёта.

Прогресс сохраняется в localStorage текущего браузера. В режиме инкогнито или при очистке данных он может исчезнуть. При замене набора вопросов начните новую игру. Звук включается отдельной кнопкой.

## GitHub Pages

Загрузите содержимое этой папки в нужный репозиторий. В Settings → Pages выберите публикацию из ветки и папку с `index.html` (например, корень `main`). Не заменяйте существующий сайт без проверки его файлов. Репозиторий проекта: https://github.com/NikolayGogol-star/anastasia-chgk . Адрес GitHub Pages: https://nikolaygogol-star.github.io/anastasia-chgk/ .

Видео, тексты и правильные ответы статического сайта доступны посетителям в исходных файлах. Этот вариант подходит для дружеской игры с самостоятельной оценкой. Для офлайн-копии скачайте всю папку вместе с видео; без интернета используются резервные системные шрифты.

## Что готово

Игровой стол с 13 секторами, случайный выбор без повторов, видеоплеер, минутный таймер, пауза, ввод ответа, разгадка, самооценка, счёт до 6, просмотр оставшихся вопросов, сохранение и сброс прогресса, адаптивный интерфейс.

Оформление, поздравление и вопросы — черновые; заменяются перед мероприятием. Блиц и суперблиц пока не реализованы.
